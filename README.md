# Card Payoff Planner

Credit card payoff calculator that installs on any phone as a home-screen app and works offline.

- Interest uses the average daily balance method with daily compounding (APR ÷ 365), statement by statement.
- Payment options: fixed monthly payment or minimum only, plus a monthly extra, a yearly extra and one-time payments.
- Shows the payoff date, total interest and a comparison against minimum payments, plus a balance chart and a month-by-month schedule.

## Install on a phone
Open the GitHub Pages address for this repo, then:
- **iPhone:** in Safari, tap Share, then Add to Home Screen.
- **Android:** in Chrome, open the ⋮ menu, then Install app.
